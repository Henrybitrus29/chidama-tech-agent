# Battery storage

## What we install
We install 13.5 kWh home batteries. Each installed battery typically costs between $9,500 and $12,000.

## Backup power
One battery can back up essential loads such as the refrigerator, lights and internet. Backing up an entire home usually takes two or more batteries.

## Adding later
You can add a battery to an existing Brightside system at any time. A design review is required first.

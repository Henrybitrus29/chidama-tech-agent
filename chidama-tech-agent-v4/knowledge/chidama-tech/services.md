# Services

## AI engineering
We build retrieval-augmented generation (RAG) pipelines, fine-tuning workflows and vector database integrations. We also build autonomous AI-driven terminal agents such as GEMCODE.

## Secure full-stack engineering
We build web applications with React, Next.js and Tailwind on the front end and Python with FastAPI on the back end. We design cloud-native architecture and ship containerized deployments.

## Automation
We build B2B lead pipelines in n8n with data sanitization, and custom Python scripts for data ETL and scraping.

## Pre-deployment security hardening
Before launch we test applications against the OWASP Top 10 using tools such as ZAP, Burp, sqlmap and nmap.
